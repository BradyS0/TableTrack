Creator: draw outer walls.

Editor tools

Shared Controls

  • Wheel = zoom
  • LMB+RMB+drag = pan

Layout Creator Controls

  • Left-Click = to add wall points
  • Right-Click = to remove latest point
  • Shift = straight segment
  • Left-Click first point to complete floor plan after placing at least 3 points

Layout Editor Controls

  • Select item from the options, point and click inside the floor plan to place the item
  • Drag item outside = delete
  • Right-click item = context menu
